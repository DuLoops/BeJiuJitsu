# Features

1. Explore Screen  
   1. Learn  
      1. Learn BJJ on materials provided by admin(me) and other users.  
         1. Categories: Hot(recommended), Follow, roll (competition or train \- tags of used skills), Skill (Skill description like Wikipedia, clipped footages), Fundamentals, Train tool, Mindset, Discussion  
         2. Post  
            1. Video / photo / link  
            2. Text  
   2. Social  
      1. View posts of my follows  
      2. Profile  
         1. Follow training parter or gyms  
         2. View my public posts  
2. Record/post/create/log  
   1. Record/upload Roll  
      1. Record Setup (optional)  
         1. Timer   
         2. Define fighters (record name, if following then link the user by id)  
         3. role or competition  
         4. Start  
      2. While Recording  
         1. Top buttons \- divided for left and right for fighter1 and fighter2  
            1. Takedown / sweep  
            2. Pass / control  
            3. Submission  
         2. Bottom  
            1. End roll  
      3. After Recording/uploading  
         1. Edit    
            1. Link to skill and adjust clip  
            2. Note  
         2. Private / public  
         3. Save  
   2. Post on social  
      1. Photos or video or link  
      2. Post   
      3. Other users can like or reply  
   3. Create/update Skill  
      1. Category / Skill / note / Skill sequence  
   4. Log training  
      1. Date  
      2. Log (can have multiple)  
         1. Type   
            1. Strength, cardio, stretching, warm up, Gi, Nogi, Wrestling, Drill, Skill learning, Eco Game, Roll  
         2. Occurrence (hr, rolls, reps)  
         3. Create/Edit skill  
         4. Note  
   5. Log Competition  
      1. Date  
      2. Tournament  
      3. Detail (can have multiple)  
         1. Gi / nogi / other  
         2. Win / Lose / Tie  
         3. Method  
            1. Sub, points, decision , disqualification, forfeit, other  
         4. \+ video, skill, note  
3. Progress Screen  
   1. Log  
      1. Training Calendar  
      2. List of logs  
         1. Filter by tags (tags should display number of logs)  
            1. Roll, training, competition  
   2. Skill  
      1. View all skills / Edit  
      2. Filter by tags  
      3. Learning skills (view history of posts)

# User personas

* Paul  
  * White belt, 18, Enthusiastic learner, like watching videos and photo but not words  
* Evan  
  * Blue belt, 25, Like to record training, methodical, compete often and like to review the competition and training history.  
* Chloe  
  * Purple belt, 30, Like to connect with training partner and share the progress, social, Like sharing newly learned skills and instructional videos  
* John  
  * Black belt, 40, coach, likes to share the gym’s learning materials, wants to host a tournament, promotes the gym, and reviews his students' competition videos.

# User stories

1. As a white Belt BJJ practitioner Paul, I want to learn fundamentals, good solo drills, training methods, and get free instructional YouTube videos to learn skills.   
2. As a Blue Belt BJJ practitioner Evan, I want to record my roll with a specialized camera for rolling.  
   1. I want the filmer to mark skills used in the roll.  
   2. I want to view the roll and input skill names used and clip the footage and post it.  
   3. I want to review clips by skills.    
3. As a Purple Belt BJJ practitioner Chole, I want to follow my gym and connect with fellow practitioners.   
   1. I want to see what the coach was teaching today that were posted.  
   2. I want to see how my friend’s training progress is going by viewing their public posts.  
4. As Chole, I want to see the discussion forum and see the latest trend in competitions.  
5. As a BlackBelt Coach, John. I want to get many followers for my gym, earn revenue, and create an online community.  
   1. I want to have gym account  
   2. I want to host a superfight by posting in the community.  
   3. I want to post videos from the gym’s superfight competition.
